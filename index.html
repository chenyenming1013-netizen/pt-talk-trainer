一次好的治療說明，大致走這六步

  1. 關心開場：先問生活，不先談治療。
  2. 探詢痛點：哪個動作痛、影響了什麼、持續多久。
  3. 找出目標：病人真正想恢復的是什麼（上班、旅遊、抱孫）。
  4. 衛教連結：用白話解釋為什麼會痛、為什麼之前的方法不夠。
  5. 提出選項：基本方案與進階方案並列，說清楚差別與費用。
  6. 處理顧慮並邀約：回應擔心，請病人做一個小決定。

業績來自信任，不是話術壓力

好的說明是讓病人「聽懂自己的問題，選到適合的方案」。自費項目要符合適應症、清楚告知費用與可能次數，不保證療效。

AI 教練會把「誇大療效、製造恐懼、不給選擇」列為扣分項。病人真的不適合震波時，推薦正確方案才是高分。

Gemini API 連線

金鑰只存在這台裝置的瀏覽器裡，不會上傳到任何地方，只會直接送到 Google。金鑰由診所負責人統一申請後貼上即可，同仁不需要自己申請。大家共用同一份免費額度，出現「次數用完」時等一分鐘再試。

如何申請免費金鑰
  1. 用 Google 帳號登入 Google AI Studio（aistudio.google.com）。
  2. 點左側或右上角的「Get API key」，再按「Create API key」。
  3. 複製產生的金鑰（開頭可能是 AIza 或 AQ.），貼到上面的欄位並按「儲存並測試連線」。
  4. 看到「連線成功」就可以回到「情境演練」開始練習。

免費方案有每分鐘與每日次數上限，出現「次數用完」時等一分鐘或隔天再用。免費方案的內容可能被 Google 用於改進模型，請不要輸入真實病人的姓名、病歷號或可辨識資料。模型若被 Google 停用，改選其他模型或自行輸入新名稱即可。
